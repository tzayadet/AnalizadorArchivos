Analizador de
Archivos PRO

Utilidad de escritorio para localizar archivos, combinar filtros, detectar duplicados y revisar el espacio ocupado por los resultados. Está construida con la biblioteca estándar de Python y ofrece un flujo de trabajo local para Windows, macOS y Linux.

Código fuenteDocumentación y usoCompilador Windows
01 / SEARCH

Filtros combinables

Nombre, extensión, contenido, tamaño y fechas. Los criterios pueden combinarse en modo Y u O.

02 / INTEGRITY

Duplicados SHA-256

Identifica coincidencias exactas mediante hash y permite localizar archivos con el mismo tamaño.

03 / REPORTING

Espacio y errores

Resumen de espacio, errores de acceso y exportación de resultados a CSV.

04 / OPERATIONS

Revisión de resultados

Abrir ubicaciones, copiar rutas, mover archivos con renombrado anti-colisión y gestionar grupos de duplicados.

Atención: las acciones de eliminación son permanentes y no utilizan la Papelera de reciclaje. Revisa las rutas y los grupos seleccionados antes de confirmar. Para una revisión reversible, utiliza primero la opción de mover duplicados a otra carpeta.

Showcase informativo. La aplicación de escritorio no se ejecuta en el navegador. El repositorio incluye el código fuente y un script para generar un ejecutable Windows con PyInstaller.
